# limits

Локальный CLI для лимитов и стоимости подписок Claude/Codex. Команды,
источники данных, установка и формат вывода описаны в [README.md](README.md).

- `watch.py` — CLI и получение usage; `stats.py` — отображение статистики;
  `metadata.py` — метаданные подписок; `worth.py` — расчёт стоимости.
- Python 3.9+, только стандартная библиотека. Проверка из корня:
  `/usr/bin/python3 -m unittest -v`. Тесты используют временные каталоги
  и заглушки провайдеров; живые аккаунты для них не нужны.
- `limits --json` обращается к провайдерам и обновляет кеш Codex,
  `--observe` пишет историю; это не офлайн-проверки. Переключение аккаунта
  в интерактивном экране меняет активный профиль — для проверки кода
  его не выполнять.
- Не смешивать usage разных аккаунтов, подписок и окон лимита. Данные
  провайдера, локальные наблюдения и ручные метаданные различать явно;
  отсутствие данных не выдавать за нулевое потребление.
- `~/.local/share/limits/observations.jsonl` — накопленная история;
  не удалять ради исправления кеша. Кеш и его восстановление описаны в README.
  Не копировать авторизационные данные в конфиги, фикстуры или вывод.
- Установленная команда использует `watch.py` основного checkout;
  учитывать это при проверке изменений. Пользовательские конфиги и
  наблюдения не нужны для обычных тестов.
